完全正确要求该样本所有问题均命中且没有误报；无问题样本要求没有任何预测问题。
无问题样本误报率以样本计数，不是 FP/全部预测问题。

耗时、Token、完全正确样本数均为假设汇总值，没有逐样本测量依据或置信区间。
